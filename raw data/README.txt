# Raw Dataset Information

**Project:** Strategic Planning for Virtual Construction Intelligence

**Dataset:** Capital Projects Dashboard – Citywide Schedule History and Variance

**Source:** NYC Open Data

**Official dataset link:**  
https://data.cityofnewyork.us/City-Government/Capital-Projects-Dashboard-Citywide-Schedule-Histo/95tx-snak/about_data

The raw dataset is not included in this repository. It can be accessed through the official source link above.

This dataset was used to develop the project's Power BI dashboard, which explores historical schedule variance, reporting-period trends, and comparisons across managing agencies.
